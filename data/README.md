# Retail Sales Dataset

This folder contains the original simulated retail sales dataset used for the Retail Sales & Customer Performance Analysis project.

## Dataset Overview

The workbook contains three primary tables:

- Sales: Transaction records, dates, products, customers, quantities, sales amounts and unit costs.
- Customers: Customer demographics, regions, gender and income levels.
- Products: Product names, categories, brands, colours and weights.

## Dataset Period

January 2024 – June 2025.

## Purpose

The dataset was used to demonstrate data cleaning, data modelling, KPI development, business intelligence and dashboard reporting.

Note: This is a synthetic portfolio dataset, not confidential company data.
